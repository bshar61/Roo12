# NEXUS ALPINE — BSHAR SALMAT SY

نسخة عربية RTL بواجهة ثلجية وخضراء للجوال والكمبيوتر. حُفظ الملف المرفق في `reference/index-original.html`. النسخة المطورة تستخدم واجهة وخادمًا وقاعدة بيانات لحماية التراخيص والنتائج؛ ملف HTML وحده لا يوفّر هذه الحماية.

## الوظائف

غرف الإشارات والمؤشرات والأزواج والنتائج ومساعد الذكاء ومصدر الأسعار والإدارة. عشرة أزواج OTC فريدة؛ USD/COP مكرر في الطلب وأُضيف مرة واحدة. تثبيت زوج أو المسح بالتناوب كل 10/20/30/60 ثانية. شموع دقيقة، EMA 9/21/50 وBollinger ودعم ومقاومة وRSI وCCI وMACD، مع إظهار كل الطبقات بزر واحد وتكبير الشارت وتحريكه.

محرك العوامل الخمسة يعتمد على الشموع المغلقة، ويشترط 80% توافق للنشر. درجة التوافق ليست احتمال الفوز. إشارة واحدة نشطة للعضو؛ دخول بداية دقيقة وخروج بعد 1/2/3/5 دقائق. WIN / LOSS / DRAW / UNVERIFIED مع حفظ الأسعار والتوقيت الفعلي، سجل دائم، فلترة وتصدير CSV. المحاكاة معزولة عن السوق الحي. لا تُنفذ أوامر مالية في Quotex.

رموز شهرية من 6 أرقام، تبدأ 30 يومًا من أول تفعيل. يتحقق الخادم من الصلاحية في كل طلب؛ جلسة الإدارة 30 دقيقة، وتحديد محاولات الدخول، وإلغاء فوري للجلسات عند إلغاء الترخيص. رمز دخول الإدارة مضبوط على الرمز الذي حدده المستخدم، ويُتحقق منه على الخادم؛ لا يُضمّن في JavaScript.

اتصالات OpenAI Responses، Claude/Anthropic Messages، Google Gemini GenerateContent، وChat Completions-compatible. مفاتيح AI مشفّرة على الخادم ولا تُعاد للمتصفح. أسماء النماذج يحددها صاحب الحساب. ليست جميع واجهات AI ذات بروتوكول واحد.

## إعدادات السيرفر القابلة للتغيير

الافتراضي **عند أول تشغيل فقط**:
`https://quotexpriceserver-ex9bwudd.b4a.run`

من غرفة الإدارة ← الاتصالات ← إعدادات السيرفر ← رابط سيرفر الأسعار:

1. أدخل الرابط الجديد واضغط «فحص وحفظ الرابط».
2. يُزال `/` الأخير ويُشترط HTTPS.
3. يطلب الخادم `/health` من الرابط الجديد **دون مفاتيح**.
4. يعتمد الرابط فقط عند رد HTTP ناجح وJSON يحوي `"server":"ok"`.
5. عند الفشل تظهر «فشل الاتصال بالسيرفر الجديد»، ويبقى الرابط السابق العامل.
6. عند النجاح يُحفظ في D1 وتستخدمه الطلبات اللاحقة فورًا، وبعد إعادة التشغيل أيضًا.

تغيير المصدر يوقف تحقق الإشارات الحية المعلقة ويضعها UNVERIFIED حتى لا تُقارن أسعار من سيرفرين. تاريخ الشموع مفصول بحسب عنوان السيرفر. لا يوجد اتصال مباشر من البوت إلى Quotex.

## عقد الاتصال

| العملية | الطلب | الاعتماد |
|---|---|---|
| الحالة | GET /health | دون مفتاح |
| جميع الأزواج | GET /prices | X-API-Key من PRICE_SERVER_API_KEY |
| الجلسة | POST /admin/session، JSON يحوي ssid | Bearer من PRICE_SERVER_ADMIN_SECRET |

أضف في **متغيرات بيئة خادم البوت**:

- `PRICE_SERVER_API_KEY`: نفس القيمة الموجودة باسم `API_KEY` في سيرفر Back4app.
- `PRICE_SERVER_ADMIN_SECRET`: نفس القيمة الموجودة باسم `ADMIN_SECRET` في سيرفر Back4app.

اختلاف أسماء المتغيرات بين العميل والسيرفر مقصود؛ القيم متطابقة. لا تضع القيم في HTML أو Git. المفاتيح لا تُحفظ في المتصفح ولا تُطبع في السجلات. لا يُطبع SSID. تعديل أسرار البيئة يحتاج تطبيق إعدادات الاستضافة؛ **تعديل الرابط من الإدارة لا يحتاج إعادة نشر**.

أرسل SSID من الإدارة، ثم يفحص البوت `/health`. قراءة الأسعار تتطلب `authorized=true`؛ فتح الشبكة وحده لا يجعل السعر حيًا. يلزم سعر مؤرخ حديث لتظهر حالة LIVE.

## استجابة الأسعار

تُدعم خرائط أو قوائم داخل `prices` أو `data`. تطابق الرموز دقيق؛ لا يُستبدل `EURUSD_otc` بسعر EURUSD العادي.

```json
{"prices":{"EURUSD_otc":{"price":1.08123,"timestamp":1800000000,"payout":85,"is_open":true}}}
```

توقيت كل زوج يقبل Unix بالثواني/الميلي ثانية أو ISO. بدائل الاسم: `timestamp`, `updated_at`, `time`, `ts`. السعر يقبل `price`, `close`, `value`. العائد اختياري كنسبة من 0 إلى 100. إن عاد السعر دون توقيت، يظهر للعرض فقط؛ لا نخترع تاريخًا ولا نستخدمه لتسوية نتيجة موثقة.

## دوال Python

`python/price_server.py` يوفر:

```python
from price_server import (
    get_saved_server_url, save_server_url,
    get_health, get_all_prices, get_price, send_ssid,
)

health = get_health()
prices = get_all_prices()
eur_otc = get_price("EURUSD_otc")
# save_server_url("https://your-new-server.b4a.run/")
# send_ssid(ssid_from_secure_input)
```

دالتا `get_saved_server_url()` و`save_server_url(url)` تستخدمان SQLite دائمًا. حدد `PRICE_SERVER_CONFIG_PATH` داخل قرص دائم إذا شغّلت Python داخل حاوية؛ الافتراضي `data/price_server_settings.sqlite3`. تغيير الرابط يُقرأ عند كل استدعاء ولا يحتاج إعادة تشغيل. فشل الفحص يبقي القيمة السابقة. إعدادات نسخة Python مستقلة عن D1 الخاص بالموقع، فهما بيئتا تشغيل منفصلتان؛ استخدم الدوال في البوت Python الحالي عند الحاجة.

```sh
python -m venv venv
# Linux/macOS: source venv/bin/activate
# Windows PowerShell: .\venv\Scripts\Activate.ps1
pip install -r python/requirements.txt
python python/connect.py
```

اضبط متغيرات البيئة قبل التشغيل. ملف `.env.example` نموذج فارغ؛ Python لا يحمّله تلقائيًا.

## حدود التحقق

- لم يُختبر اتصال أسعار حقيقي ولا AI حقيقي لأن مفاتيح البيئة وSSID والنموذج غير متاحة. اختُبر العقد بطلبات محاكاة، دون إرسال أسرار أو تنفيذ صفقات.
- `/prices` لقطات، وليس تاريخ شموع أو كل Tick؛ شموع البوت مبنية من العينات وقد تختلف عن شموع المنصة. لا تُختلق شموع ماضية.
- يحتاج إصدار الإشارات 60 شمعة دقيقة مكتملة متتالية. أول عينة خلال 3 ثوانٍ من بداية الدقيقة، وآخرها ضمن 8 ثوانٍ من نهايتها، دون فجوة تتجاوز 8 ثوانٍ، وبثماني عينات على الأقل. قد يطول الانتظار إذا تقطع المصدر.
- الرصد والتوليد الآلي يحتاجان بقاء صفحة البوت مفتوحة. هذه النسخة ليست خدمة مراقبة 24/7 بعد إغلاق الهاتف. تبقى التراخيص والنتائج محفوظة، لكن فوات نافذة الدخول أو الخروج يسجل UNVERIFIED بدل التخمين.
- تُسجل أول عينة بعد موعد الدخول/الخروج ضمن 3 ثوانٍ، مع توقيتها الفعلي. عند الانقطاع لا تُحسب خسارة أو فوز مصطنع.
- نسبة الفوز = WIN / (WIN + LOSS). التعادل وغير المتحقق مستبعدان. الأثر المالي تقدير مقارنة، وليس ربح حساب منفذًا. عائد 85% في المحاكاة فقط، وفي السوق الحي يُستخدم العائد إن أعاده المصدر.
- السجل يعرض آخر 1000 إشارة لكل مصدر. ملف CSV مستورد للتحليل التاريخي فقط.
- النصوص التسويقية المطلوبة موجودة مع توضيح أن الجوائز والإرشاد والرسائل الخاصة ولوحات المتصدرين غير مفعلة، ولا توجد دقة أو أرباح مضمونة.
- النشر خاص بالمالك. إنشاء رمز شهري لا يمنح تلقائيًا صلاحية دخول موقع خاص لأشخاص آخرين؛ يلزم ضبط مشاركة الموقع عند توزيعه.
- لم يُجر اختبار بصري في متصفح. فُحصت الأنواع والبناء والحسابات والحماية وعقود HTTP آليًا.

## ربط الذكاء من داخل البوت

1. اضغط أيقونة الذكاء في الشريط العلوي، ثم «ربط الذكاء الاصطناعي».
2. أدخل رمز الإدارة. ينتقل البوت مباشرة إلى تبويب ربط الذكاء.
3. اختر OpenAI أو Claude أو Gemini أو مزودًا متوافقًا.
4. اكتب معرّف النموذج وألصق مفتاح API الكامل في الحقل الداكن. لا تستخدم رابط ChatGPT أو كلمة المرور بدل المفتاح.
5. اضغط «حفظ واختبار الاتصال». سترى نتيجة الاختبار داخل الشاشة؛ الحفظ وحده لا يعني نجاح الاتصال. قد يستهلك الاختبار من رصيد API عند مزودك.
6. افتح مصدر أسعار أو المحاكاة ثم اطلب تحليل الزوج. ربط الذكاء لا يربط مصدر الأسعار تلقائيًا.


## Quotex V26 Aurora — المتطلبات والتشغيل

- Node.js 22.13 أو أحدث، وpnpm. إصدارات الاعتماديات كاملة في `package.json` و`pnpm-lock.yaml`.
- محرك الشارت `VAP Candle Core` مكتوب داخل المشروع باستخدام Canvas عالي الدقة، مع React 19 وVinext وCloudflare Workers وD1.
- Python 3.10 أو أحدث لاستخدام عميل الأسعار الاختياري؛ `pip install -r python/requirements.txt`.
- لتثبيت المشروع: `pnpm install --frozen-lockfile`. للمعاينة: `pnpm dev`. للبناء: `pnpm build`.
- `.env.example` يوضح مفاتيح البيئة المطلوبة؛ لا تنقل قيم الأسرار إلى الكود. تشغيل خدمات الخلفية يتطلب ربط D1 وتطبيق ملفات `drizzle/*.sql`، وتوفّر بيئة Workers. النسخة المنشورة مزودة بهذا الربط.
- داخل الغرف تظهر ساعة UTC؛ مواعيد الدخول والخروج تستخدم التوقيت نفسه. تحسب الإشارة أقرب حد دقيقة يبعد 10 ثوانٍ على الأقل عن وقت النشر في الخادم. وصولها للجهاز قد يتأخر بحسب الشبكة؛ العد التنازلي يعبّر عن الوقت المتبقي الفعلي.
- لا يتغير سعر الدخول المسجل نتيجة وصول طلب متابعة آخر بالتزامن، ولا تُقبل أسعار مؤرخة في المستقبل لتسوية النتائج.
- الشموع مصدرها سيرفر الأسعار الخاص بك؛ محرك الرسم لا ينشئ أسعارًا ولا ينفذ صفقات مالية.
- المصدر الحي غير مختبر هنا لعدم توفر مفاتيح الأسعار/SSID. ربط الذكاء يحتاج مفتاحك والنموذج المتاح في حسابك.


## غرفة إشارات VAP والنسخة HTML

بعد بناء المشروع يمكن إنشاء ملف HTML واحد بالأمر:

ملف HTML يحتوي الواجهة كاملة، لكنه يحتاج أن يُخدّم من أصل المشروع نفسه حتى تعمل مسارات `/api`. تشغيله مباشرة بصيغة `file://` يعرض الواجهة، ولا يوفر خادم التراخيص أو الأسرار أو قاعدة البيانات.

## حالات الأزرار

أزرار المسح، تثبيت الزوج، طبقات المؤشرات والتوليد التلقائي تستخدم `aria-pressed`. اللون الزمردي يعني أن الوظيفة مفعلة، والحالة البيضاء تعني أنها متوقفة. مزود الأسعار المختار ومفاتيح المؤشرات تعرض حالتها بصريًا على الهاتف وسطح المكتب.
